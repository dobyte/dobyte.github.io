# 1.1 快速开始

# 1.1.1 Go编译器安装

  1. 安装Go多版本管理器（推荐）

    • Linux/macOS下自动安装Go多版本管理器（适用于 bash、zsh）
    $ curl -sSL https://raw.githubusercontent.com/voidint/g/master/install.sh | bash
$ cat << 'EOF' >> ~/.bashrc
# 可选。检查g别名是否被占用
if [[ -n $(alias g 2>/dev/null) ]]; then
    unalias g
fi
EOF 
$ source "$HOME/.g/env"
    1

    • Windows下自动安装Go多版本管理器（适用于 pwsh）
    $ iwr https://raw.githubusercontent.com/voidint/g/master/install.ps1 -useb | iex
    1

  2. 安装Go编译器

    $ g install 1.25.0
    1

# 1.1.2 工具链安装

  1. 安装protobuf编译器（使用场景：开发mesh微服务、使用protobuf作为与客户端通信的协议）

    • Linux, using apt or apt-get, for example:
    $ apt install -y protobuf-compiler
$ protoc --version  # Ensure compiler version is 3+
    1
    2
    • MacOS, using Homebrew:
    $ brew install protobuf
$ protoc --version  # Ensure compiler version is 3+
    1
    2
    • Windows, download from Github (opens new window):

  2. 安装protobuf go代码生成工具（使用场景：开发mesh微服务、使用protobuf作为与客户端通信的协议）

    $ go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
    1

  3. 安装grpc代码生成工具（使用场景：使用GRPC (opens new window)组件开发mesh微服务）

    $ go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest
    1

  4. 安装rpcx代码生成工具（使用场景：使用RPCX (opens new window)组件开发mesh微服务）

    $ go install github.com/rpcxio/protoc-gen-rpcx@latest
    1

  5. 安装gorm dao代码生成工具（使用场景：使用GORM (opens new window)作为数据库orm）

    $ go install github.com/dobyte/gorm-dao-generator@latest
    1

  6. 安装mongo dao代码生成工具（使用场景：使用MongoDB (opens new window)作为数据库orm）

    $ go install github.com/dobyte/mongo-dao-generator@latest
    1

# 1.1.3 Docker环境安装

  1. 安装docker

进入docker (opens new window)官网下载最新版docker (opens new window)安装包安装

  1. 安装docker-compose
  • Linux
$ sudo curl -L "https://github.com/docker/compose/releases/download/v2.36.2/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
$ sudo chmod +x /usr/local/bin/docker-compose
1
2

  • MacOS，docker desktop (opens new window)中已内置docker-compose，故无须单独安装

  • Windows, download from Github (opens new window):

  1. 安装开发组件
$ cd ./docker
$ docker-compose up -d
